NFX Location PRO menambahkan login akun, langganan, dan pengikatan akun ke satu perangkat.

- Pengguna masuk dengan nomor HP dan kata sandi. Admin masuk dengan nama pengguna `admin`.
- Admin dapat membuat akun, menambahkan hari langganan, dan menyetujui atau menolak perpindahan perangkat.
- Perangkat pengganti harus mendapat persetujuan admin. Persetujuan mencabut sesi perangkat lama di server.
- Ikon vektor NFX yang baru menggantikan ikon peluncur. Tautan Buy Me a Coffee telah dihapus dari aplikasi.

APK memakai package ID `moe.shizuku.privileged.api` dan sertifikat rilis repositori ini sehingga dapat memperbarui rilis sebelumnya dengan sertifikat yang sama.
