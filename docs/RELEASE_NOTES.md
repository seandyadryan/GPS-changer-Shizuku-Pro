Fork lengkap Shizuku-Next dengan nama Shizuku Pro.

- Mempertahankan Home, Apps, Modules, Labs, Settings, ADB/wireless debugging, root, shell, file manager, installer, dan fitur upstream lainnya.
- Pembaruan dan laporan bug diarahkan ke repositori ini.
- Build release bertanda tangan tetap, dengan unit test dan pemeriksaan kompatibilitas API Android.
- GitHub Actions dijalankan manual agar push biasa tidak memakai runner.

Android 7.0 atau lebih baru. Wireless debugging memerlukan Android 11 atau lebih baru.
Package ID tetap `moe.shizuku.privileged.api`. Hapus instalasi Shizuku lain yang memakai tanda tangan berbeda sebelum memasang APK ini; hentikan server lama atau reboot terlebih dahulu.

Ini adalah fork manajer Shizuku lengkap sesuai cakupan proyek. Nama repositori tidak berarti ada fitur pengubah koordinat GPS tambahan.

Upstream dan lisensi: [rushiranpise/Shizuku-Next](https://github.com/rushiranpise/Shizuku-Next), Apache 2.0; kredit lengkap dipertahankan di README upstream.
